## 🌟 Executive Overview

**Utkarsh City** is an immersive, high-fidelity 3D web experience that bridges luxury Dubai-inspired architecture with interactive open-world automotive cinematography. Built using **React 19**, **Three.js**, **React Three Fiber (R3F)**, **Drei**, and **Tailwind CSS**, it transforms a traditional software engineering resume into a dynamic, explorable cyberpunk-metropolis.

### Key Highlights
- 🏎️ **Autonomous & Manual Vehicle Driving:** Real-time physics calculation ($v \times \Delta t / r$), kingpin steering, dynamic suspension pitch/roll, and dual-mode autonomous cruising along an elliptical grand boulevard.
- 🏛️ **8 Physical Themed Architectural Modules:** Every resume section is rendered as a monumental 3D building flanking the grand highway.
- 🎯 **Interactive Proximity Detection & E-Key Prompt:** Smart distance calculation automatically detects nearby landmarks, smoothly decelerates the vehicle, and offers contextual exploration modals.
- 🏎️ **Bespoke Supercar Showroom:** 360-degree interactive vehicle inspection platform featuring an aerodynamic GT3 twin-turbo hypercar with active turntable rotation, camera presets, and real-time telemetry.
- 👤 **Executive Portrait Monolith:** High-contrast, un-tonemapped authentic photographic totem (`sRGBColorSpace`) paired with an auto-centered 3D character avatar.
- 📱 **Adaptive 60 FPS Mobile Architecture & Accessible 2D Fallback:** Touch controls, dynamic resolution scaling (`DPR 0.75 - 1.25` on mobile, `1.0 - 2.0` on desktop), and a full-featured independent 2D view (`?view=2d`).

## 🎮 Navigation & Interactive Controls

### Keyboard Controls
| Key | Function |
|---|---|
| <kbd>W</kbd> / <kbd>▲</kbd> | Accelerate vehicle forward |
| <kbd>S</kbd> / <kbd>▼</kbd> | Reverse / Brake vehicle |
| <kbd>A</kbd> / <kbd>◄</kbd> | Steer vehicle left |
| <kbd>D</kbd> / <kbd>►</kbd> | Steer vehicle right |
| <kbd>Space</kbd> | Handbrake (immediate planted stop) |
| <kbd>E</kbd> | Interact / Explore landmark when prompted |
| <kbd>1</kbd> – <kbd>8</kbd> | Fast-travel camera to corresponding scene checkpoint |
| <kbd>M</kbd> | Toggle audio synthesis & ambient soundscape |
| <kbd>Esc</kbd> | Close active inspection modal / Exit free drive |

### Mouse & Touch Controls
- **Dock Navigation:** Click any module badge on the top glassmorphic navbar to trigger a smooth cinematic camera glide.
- **360° Orbit:** Click-and-drag (or touch-drag on mobile) inside the Supercar Showroom to inspect vehicle angles.
- **2D Mode:** Click `2D View` in the top right to switch to the lightweight, accessible flat layout.

## ⚡ Performance & Optimization Engineering

1. **Strategic Code Splitting:** Rollup chunks split vendor modules (`vendor-r3f`, `vendor-react`, `vendor-ui`, modals) so the initial JavaScript payload remains small and loads under 1.5 seconds.
2. **Dynamic DPR & Mobile Downscaling:** Mobile devices automatically disable expensive real-time shadow passes and clamp Device Pixel Ratio between 0.75x and 1.25x for solid 60 FPS performance.
3. **Texture Gamma & Contrast Integrity:** Textures utilize `THREE.SRGBColorSpace` with mipmapping. The authentic portrait utilizes `toneMapped={false}` on a solid obsidian backing plate to ensure 100% true-color reproduction under any lighting condition.
4. **Memory Management & Disposal:** Cloned scenes, materials, geometries, and audio nodes are cleanly disposed of upon modal closure or component unmounting to prevent WebGL context memory leaks.

## 🛠️ Local Development & Build

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- [npm](https://www.npmjs.com/) (version 9.0 or higher)

### Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/arorautkarsh05-web/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start local development server (Vite HMR)
npm run dev

# 4. Run production build (TypeScript check + Vite bundle)
npm run build

# 5. Preview production build locally
npm run preview

# 6. Run automated 37-point QA verification audit
node scripts/qa-audit.cjs
```
